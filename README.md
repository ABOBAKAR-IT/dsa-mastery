# DSA Mastery

Concept-first Data Structures and Algorithms. Practice language: JavaScript (Node.js).

## Structure
- `00-foundations/`      complexity, recursion, bits, math
- `data-structures/`     each DS: README (concept), implementation/, problems/
- `algorithms/`          each algorithm or pattern: README, template.js, problems/
- `system-design-dsa/`   LRU, rate limiter, consistent hashing, bloom filter
- `revision/`            mocks, weekly reviews, pattern drills
- `docs/`                cheatsheets, mistakes log, templates

## Learning loop
Concept -> Implement from scratch -> Solve 8-15 problems -> Log mistakes -> Revise at +3, +7, +21 days
